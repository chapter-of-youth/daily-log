Project Plan

Home Cafe — 집에서 만드는 카페 음료

카페 음료 레시피를 검색하고, 재료와 만드는 법까지 한 번에 확인하는 앱

01. 기획 배경

'딸기 칵테일'을 검색하면 딸기로 만든 칵테일이 한꺼번에 나오고, 메뉴를 누르면 필요한 재료와 제조 방법, 칼로리까지 볼 수 있는 앱(Tipsy)이 있습니다. 이 구조가 레시피를 찾는 사람에게 아주 편하다고 느꼈습니다.

이 방식을 카페 음료에 적용해, 집에서 카페 음료를 만들어 마시고 싶을 때 검색 한 번으로 레시피를 알아볼 수 있는 서비스를 만들고 싶습니다.

02. 누가 보나요

보는 사람
카페 음료를 집에서 만들어 마시고 싶은 사람, 카페 비용을 아끼고 싶은 사람, 홈카페를 막 시작한 입문자
보여주고 싶은 것
음료별 필요한 재료, 만드는 순서, 칼로리와 난이도를 한눈에 볼 수 있는 레시피

03. 디자인 방향

사이트명 / 로고
home cafe. (집 + 카페. 소문자 텍스트 로고, 마침표만 칠판 그린 포인트)
메인 컬러
브라운(#6b4426) + 베이지/크림(#f7efe2) 바탕, 칠판 그린(#2c4538)을 포인트로
레이아웃 분위기
칠판 같은 진한 초록 배경 위에 물결 모양 크림 패널을 올린 카페 메뉴판 느낌. 굵고 큰 타이틀, 알약(pill) 모양 검색창·메뉴·태그
메뉴 구성
Home · Menu · Search · About (4개, 알약 모양 내비게이션)

04. 핵심 기능

기능설명우선순위
음료 검색"딸기", "라떼"처럼 키워드를 입력하면 관련 음료가 목록으로 나오기필수
음료 목록음료를 사진과 이름이 담긴 카드 형태로 쭉 보여주기필수
음료 상세카드를 누르면 필요한 재료, 만드는 방법, 칼로리, 소요 시간, 난이도 보여주기필수
카테고리 필터커피 · 라떼 · 에이드 · 티 · 스무디, HOT / ICE 로 골라 보기필수
즐겨찾기마음에 드는 레시피를 저장해두고 다시 보기나중에

05. 필요한 화면

  • 메인 — 검색창과 인기 음료, 카테고리가 함께 보이는 첫 화면
  • 검색 결과 — 검색어나 카테고리에 맞는 음료가 카드로 나오는 화면
  • 음료 상세 — 하나를 눌렀을 때 나오는 레시피 화면
    재료만드는 방법칼로리소요 시간난이도HOT / ICE

06. 얻고 싶은 것

검색 → 목록 → 상세로 이어지는 흐름을 직접 기획하고 만들어서, 집에서 카페 음료를 만들고 싶은 사람이 실제로 찾아 쓸 수 있는 레시피 서비스를 인터넷에 올려보는 경험을 하는 것이 목표입니다.
