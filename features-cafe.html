home cafe. — 기능정의서

plan-cafe.html의 핵심 기능을 구체적으로 풀어쓴 문서

01. 사용자 시나리오

시나리오 1 — 만들고 싶은 음료가 정해진 사람이 메인 화면 검색창에 "딸기"를 입력하고, 결과 목록에서 마음에 드는 음료를 눌러 레시피를 본다.
시나리오 2 — 뭘 만들지 모르는 입문자가 메인 화면의 인기 음료와 카테고리를 둘러보다가 쉬워 보이는 음료의 상세 화면으로 들어간다.
시나리오 3 — 시원한 에이드가 마시고 싶은 사람이 카테고리 "에이드"와 "ICE"를 골라 후보를 좁힌 뒤, 재료와 칼로리를 비교해 본다.

02. 기능별 상세

음료 검색 필수
목적 — 먹고 싶은 음료를 키워드 한 번으로 찾기 위해
어느 화면
메인, 검색 결과
무엇을 하면
검색창에 "딸기", "라떼" 같은 키워드를 입력하고 Enter 또는 검색 버튼을 누르면
입력값 제약
최대 20자, 앞뒤 공백은 무시한다
무슨 일이
검색 결과 화면으로 이동하고, 이름이나 재료에 키워드가 들어간 음료가 카드 목록으로 나온다. 상단에 "'딸기' 검색 결과 — 8개"처럼 검색어와 개수를 보여준다
예외 상황
① 빈 검색어로 누르면 이동하지 않고 "검색어를 입력해 주세요" 안내를 띄운다
② 일치하는 음료가 없으면 "찾는 음료가 아직 없어요" 문구와 인기 음료를 대신 보여준다
의존관계
"음료 목록"의 데이터가 있어야 결과가 나온다
음료 목록 필수
목적 — 음료를 사진과 이름으로 한눈에 훑어보게 하기 위해
어느 화면
메인(인기 음료), 검색 결과
무엇을 하면
메인 화면을 스크롤하거나, 검색·카테고리 선택으로 결과 화면에 들어오면
무슨 일이
음료가 사진·이름·HOT/ICE 태그·난이도가 담긴 카드로 쭉 나열된다. 카드에 마우스를 올리면 살짝 떠오른다
예외 상황
① 사진이 없거나 불러오지 못하면 베이지 배경에 음료 이름만 보여준다
② 음료가 하나도 없으면 "아직 등록된 음료가 없어요" 문구를 보여준다
의존관계
없음 — 검색·필터의 바탕이 되는 기능
카테고리 필터 필수
목적 — 종류와 온도로 범위를 좁혀 고르기 쉽게 하기 위해
어느 화면
메인(카테고리 태그), 검색 결과(카테고리 + HOT/ICE)
무엇을 하면
커피 · 라떼 · 에이드 · 티 · 스무디 중 알약 태그를 누르거나, HOT / ICE를 선택하면
무슨 일이
선택한 태그가 채워진(활성) 상태로 바뀌고, 조건에 맞는 음료만 카드로 나온다. 카테고리와 HOT/ICE는 함께 선택할 수 있다 ("에이드 · ICE")
예외 상황
① 선택한 태그를 다시 누르면 해제되어 전체 목록으로 돌아간다
② 조건에 맞는 음료가 없으면 "조건에 맞는 음료가 없어요" 문구를 보여준다
의존관계
"음료 목록"
음료 상세 필수
목적 — 집에서 따라 만들 수 있도록 레시피 전체를 보여주기 위해
어느 화면
음료 상세
무엇을 하면
음료 카드를 클릭하면
무슨 일이
상세 화면으로 이동해서 큰 사진과 함께 재료(분량 포함), 만드는 방법(순서대로), 칼로리, 소요 시간, 난이도, HOT/ICE 정보를 보여준다
예외 상황
① 없는 음료 주소로 직접 들어오면 "음료를 찾을 수 없어요" 화면과 메인으로 가는 버튼을 보여준다
② HOT/ICE 둘 다 가능한 음료는 두 가지 정보를 함께 보여준다
의존관계
"음료 목록"에서 카드를 눌러야 들어올 수 있다
즐겨찾기 나중에
목적 — 마음에 드는 레시피를 저장해두고 다시 보기 위해
어느 화면
음료 상세, 음료 카드
무엇을 하면
하트(♡) 버튼을 누르면
무슨 일이
하트가 채워지고(♥) 즐겨찾기 목록에 저장된다. 다시 누르면 해제된다. (저장은 우선 브라우저에만 하는 방식으로 가정)
예외 상황
① 브라우저 데이터를 지우면 즐겨찾기도 사라진다는 점을 안내한다
② 저장된 음료가 없으면 "아직 저장한 음료가 없어요" 문구를 보여준다
의존관계
"음료 상세", "음료 목록"

03. 저장되는 데이터 항목

음료 하나를 저장할 때 필요한 값들입니다. 나중에 데이터를 만들 때 이 표를 그대로 씁니다.
