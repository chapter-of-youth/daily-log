- 검색창, 인기 음료, 카테고리가 함께 보이는 첫 화면
- 칠판 그린 배경 + 물결 모양 크림 패널, 알약(pill) 모양 내비게이션·검색창·태그
- 내비게이션: Home · Menu · Search · About

[페르소나]
------------------------------------------------------------
P1. 민지 (26, 직장인) — 카페 지출을 줄이고 싶어서 집에서 라떼를 만들어 보려는 사람
P2. 하준 (22, 대학생) — 홈카페를 막 시작한 입문자. 어떤 음료가 쉬운지 모름
P3. 서연 (30, 프리랜서) — 먹고 싶은 음료가 이미 정해져 있고 레시피만 빨리 보고 싶은 사람

------------------------------------------------------------
[시나리오 1] 먹고 싶은 키워드로 바로 검색한다 (P3 서연)
------------------------------------------------------------
상황  : 딸기가 남아 있어서 "딸기 라떼"를 만들어 마시고 싶다.
목표  : 레시피를 최대한 빨리 찾는다.

1. 사용자가 home cafe. 에 접속한다.
2. 메인 화면 상단의 큰 타이틀과 알약 모양 검색창을 본다.
3. 검색창을 클릭하면 입력 커서가 활성화된다. (placeholder: "어떤 음료를 만들까요?")
4. "딸기"를 입력하고 Enter 또는 검색 버튼을 누른다.
5. [검색 결과] 화면으로 이동하고, 딸기 관련 음료가 카드 목록으로 나온다.

시스템 반응:
- 검색창에 포커스가 가면 테두리가 포인트 컬러(칠판 그린)로 강조된다.
- 빈 검색어로 제출하면 이동하지 않고 "검색어를 입력해 주세요" 안내를 띄운다.

예외 / 엣지:
- 일치하는 음료가 없으면 "찾는 음료가 아직 없어요" 문구와 인기 음료를 대신 보여준다.

------------------------------------------------------------
[시나리오 2] 인기 음료를 구경하다가 상세로 들어간다 (P2 하준)
------------------------------------------------------------
상황  : 홈카페를 처음 시작했고, 무엇을 만들지 정하지 못했다.
목표  : 다른 사람들이 많이 보는 쉬운 음료를 고른다.

1. 메인 화면에 접속해 검색창 아래로 스크롤한다.
2. "인기 음료" 영역에서 사진과 이름이 담긴 카드들을 훑어본다.
3. 카드에 표시된 HOT/ICE 태그, 난이도를 보고 쉬워 보이는 음료를 고른다.
4. 마음에 드는 카드(예: "바닐라 라떼")를 클릭한다.
5. [음료 상세] 화면으로 이동해 재료, 만드는 방법, 칼로리, 소요 시간, 난이도를 확인한다.

시스템 반응:
- 카드에 마우스를 올리면 살짝 떠오르고(hover), 이름이 강조된다.
- 카드 전체가 클릭 영역이다.

예외 / 엣지:
- 이미지 로딩 실패 시 베이지 색 대체 배경과 음료 이름만 표시한다.

------------------------------------------------------------
[시나리오 3] 카테고리로 좁혀서 찾는다 (P1 민지)
------------------------------------------------------------
상황  : 오늘은 시원한 에이드가 마시고 싶지만 정확한 메뉴는 정하지 못했다.
목표  : 종류와 온도로 범위를 좁혀 후보를 본다.

1. 메인 화면의 "카테고리" 영역으로 이동한다.
2. 알약 모양 태그(커피 · 라떼 · 에이드 · 티 · 스무디)를 확인한다.
3. "에이드" 태그를 클릭한다.
4. [검색 결과] 화면으로 이동하고, 에이드 음료 카드 목록이 나온다.
5. 같은 화면에서 HOT / ICE 필터로 "ICE"만 골라 본다.

시스템 반응:
- 선택한 카테고리 태그는 채워진(활성) 상태로 표시된다.
- 결과 상단에 "에이드 · ICE — 12개" 처럼 조건과 결과 수를 보여준다.

------------------------------------------------------------
[시나리오 4] 내비게이션으로 다른 화면을 둘러본다 (P2 하준)
------------------------------------------------------------
상황  : 서비스가 어떤 곳인지 궁금하고, 전체 메뉴를 한 번에 보고 싶다.

1. 상단의 알약 모양 내비게이션(Home · Menu · Search · About)을 본다.
2. 현재 위치인 "Home"이 활성 상태(채워진 알약)로 표시된 것을 확인한다.
3. "Menu"를 클릭하면 전체 음료 목록으로 이동한다.
4. "About"을 클릭하면 서비스 소개 화면으로 이동한다.
